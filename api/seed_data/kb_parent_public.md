# 家长须知（公开，示例稿，待园方以正式通知替换）

一、入园与离园
1. 入园时间为每天 7:30—8:00，请家长将孩子送到班门口，与老师当面交接。
2. 离园时间为 16:00—17:00，请凭接送卡接孩子；如需他人代接，请提前告知班级老师。

二、作息安排（已确认部分）
3. 7:40—8:00 为中大班晨练，按课表轮到的班级参加。
4. 9:10—9:40 为集体教育活动。
5. 10:10—11:00 为户外特色课或户外活动，包括足球、篮球、体技、户外搭建、大型玩具、科学发现等。
6. 周一至周四 15:10—16:00 为户外特色课；周五下午为教师教研时间。
7. 其他时段（早餐、午餐、午睡等）以园方最新通知为准，具体请咨询班级老师。

三、请假与健康
8. 孩子因病或因事请假，请直接联系班级老师说明，爱宝会把请假问题转给老师处理。
9. 孩子身体不适时请在家休息，返园前请告知老师情况。

四、膳食
10. 每周食谱在每周五于家长群和园门口公示，下周一至周五执行。
11. 如孩子有食物过敏，请书面告知班级老师和保健室。

五、衣物与物品
12. 请为孩子准备一套备用衣物放在班级，衣物写上名字缩写。
13. 请不要让孩子携带小玩具、零食和尖锐物品入园。

六、联系方式
14. 日常问题可以先问爱宝；涉及具体孩子的问题，爱宝会转给班级老师，老师在工作时间内回复。
